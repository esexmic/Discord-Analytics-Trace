Discord —

Token de la cuenta que mira. Discord en el navegador → F12 → Application → Local Storage → discord.com → campo token. Cuenta secundaria: es una selfbot y va contra los ToS.

Supabase —

Project Settings → API. Pegá el Project URL y la secret key (service_role). La clave pública no sirve: RLS está cerrado y el server necesita bypassearlo.

Objetivo usuario a seguir

ID del usuario (snowflake, 17–20 dígitos). Clic derecho → Copiar ID con el modo desarrollador activado. Si la cuenta está conectada, el nombre se resuelve solo; si no, queda el ID hasta el primer evento.
